# fish are friends

The site behind fisharefriends.org. Hugo builds it, GitHub Pages serves it, a push to main publishes it.

posts come from the folder ~/Desktop/fish_are_friends, one post per month folder (`August_2022`, or `August_2022__Dean River trip` for a title), synced by `./sync.sh` or the launch agent. In a month folder: a photo `Mack_the_BullTrout.jpg` is a card titled from the name with any tag text dropped (Josh_Dean_River tagged Dean River is titled Josh), in every thread its Finder tags name (or `Mack_the_BullTrout__fish,dean river.jpg` without Finder tags; no tags at all means fish; `[params.tags]` in hugo.toml renames a tag, so your fishies tag shows as fish); an optional `Mack_the_BullTrout.txt` beside it is its caption; a `Dean_River.txt` in any month folder is that river's description on every page it appears; every river or lake in the photos' tags (a tag ending in River, Creek or Lake) gets its own map card automatically, drawn on first use (BC Freshwater Atlas, then OpenStreetMap; `Rscript maps.R "Bitterroot River" "Bitteroot River"` draws under a different tag spelling); an empty `Morice_River.river` file names the month's water so photos without a water tag nest under it; `Banquet_by_Bloc_Party__P-i0jw61niE.video` is a song card (YouTube id after the double underscore, caption from `Banquet_by_Bloc_Party.txt`). A month post is organized by water: each river, lake, estuary or harbour in the tags gets its map card followed by the photos tagged with it, then photos with no water tag, then songs. A tag that names a place rather than a water (Toquaht, Ucluelet) is mapped to its water in `[params.waters]` in hugo.toml. Threads list the cards tagged with them, newest first, each linking to its month. Every photo is centre-cropped to the same 16:9 card, so crop or straighten a photo yourself before dropping it in if the centre is not the subject. Posts written by hand:

new post: `hugo new content posts/<slug>/index.md`, set `categories` to one or more of spey fishing, single hand, music, floats, fly tying, film, art, write under the front matter. Photos sit beside index.md, and go in as `![caption](photo.jpg)`: they show 484 wide on the left with a bold title (the post title, or `![caption](photo.jpg "title")`) linking to the post category and the caption beside them, and open full size on click. Maps and videos take the same width. Add `river: "Morice River"` to the front matter and put `{{< map >}}` where the river card should sit (see maps.R). Music: `{{< video ID "title" >}}your words{{< /video >}}` makes a video card with the title linking to YouTube.

new trip: `hugo new content trips/<slug>/index.md`, set `kind` to raft (three spots) or wade (four spots), fill in trip_date, where (the place, with the river in brackets), river (names the map file), meet, crew, donate and donate_url (the group that gets the donations), bring. Every card links the BC freshwater licence page from `licence` in hugo.toml, and shows the river map `assets/maps/<river>.svg` when one exists: `Rscript maps.R "Squamish River"` draws the river main stem from the BC Freshwater Atlas into a 16:9 box (needs R with sf); the river card's text is the `about` entry for that river in data/rivers.toml, which the script adds empty for you to fill. Keep `crew: []` until someone signs up. Friends sign themselves in on the card. With `signup` in hugo.toml set to the Apps Script web app URL, names live in the Google Sheet and the card shows them live (crew in the front matter is ignored); with `signup` empty, the form falls back to an email to `email` and you keep crew by hand. The script is signup.gs: new Google Sheet, Extensions, Apps Script, paste it, Deploy as web app executing as you with access for anyone, copy the /exec URL into hugo.toml.

preview: `hugo server -D`, then open http://localhost:1313/

publish: `git add -A && git commit -m "..." && git push`

check: `./test.sh`

Hold a post back with `draft: true`. Profile photo: assets/img/profile.jpg. Email: hugo.toml. Categories: threads come from tags; the sidebar nests waters by their last word (River and Creek under rivers, Lake under lakes, Estuary under estuaries, Harbour, Bay, Sound and Inlet under oceans). Older posts link straight to each month. Spots per kind: the `[params.trips]` tables in hugo.toml. Links: replace `links = []` in hugo.toml with `links = [{ name = 'a name', url = 'https://example.org' }]`. content/trips/sample-trip is the draft that test.sh builds against; leave it. Trips move from upcoming to past on the nightly rebuild; if nothing has been pushed for two months GitHub pauses that schedule, so push or run the workflow by hand from the Actions tab.
